# Yuqing Kong — Academic Homepage

A lightweight static academic homepage designed for GitHub Pages.

## Files

- `index.html` — homepage content
- `styles.css` — typography and responsive layout
- `assets/favicon.svg` — favicon

## Publishing on GitHub Pages

1. Create a repository (for example, `yourusername.github.io`).
2. Upload the contents of this folder to the repository root.
3. In GitHub: **Settings → Pages → Build and deployment → Deploy from a branch**.
4. Choose the `main` branch and `/ (root)`.

The portrait is currently loaded from a public web URL, so no image file is required in the repository. If you want the site to be completely self-contained later, save the portrait into `assets/` and change the `<img src>` in `index.html`.

The Students section is intentionally left out until the student materials are supplied.
